Plugins for ConstructCraft

Commands made by the community. They run like the built-in ones: in the app, with ccad run, from scripts and for AI agents over MCP.

    Installing a plugin

    Until ConstructCraft's plugin manager reads this index, download a plugin's archive, check its SHA-256 checksum, unpack it into a folder and load it:

    ccad --plugins /path/to/plugins plugins
ccad --plugins /path/to/plugins run <plugin>__<command> key=value

    Plugins run sandboxed: they reach the project only through ConstructCraft's commands, cannot touch files or the network, and have instruction and memory limits, unless they ask for a permission. Review a plugin before you install it anyway: the index checks entries, not what plugins do.
