InstallInstalar

Three steps to a new commandTrês passos para um comando novo

A plugin is a folder with a plugin.toml and Lua code. Its commands are named <plugin>__<command> and show up in the catalog next to the built-in ones. Um plugin é uma pasta com um plugin.toml e código Lua. Os comandos dele se chamam <plugin>__<comando> e aparecem no catálogo junto com os nativos.

  1. 1

    DownloadBaixe

    Get the .zip of the version you want from its card. It comes straight from the author's release.Pegue o .zip da versão que quiser no card dela. Ele vem direto da release do autor.

  2. 2

    VerifyConfira

    Compare its checksum with the one on the card:Compare o checksum com o do card:

    # Linux / macOS
sha256sum quick_rooms.zip
# Windows (PowerShell)
Get-FileHash quick_rooms.zip
  3. 3

    InstallInstale

    In the app, use Manage → Plugins. From the command line, install the archive into a plugins folder; it is checked and loaded the same way:No aplicativo, use Gerenciar → Plugins. Na linha de comando, instale o arquivo numa pasta de plugins; ele é verificado e carregado do mesmo jeito:

    ccad plugins install \
  quick_rooms.zip ./plugins
ccad --plugins ./plugins plugins
SecuritySegurança

Sandboxed by defaultEm sandbox por padrão

A plugin reaches your project only through ConstructCraft's commands. Anything more must be asked for, and every card shows what a plugin asks for. Um plugin só chega ao seu projeto pelos comandos do ConstructCraft. Qualquer coisa além disso precisa ser pedida, e cada card mostra o que o plugin pede.

No permissionsSem permissões

No files, no network, limits on instructions and memory. Most plugins need nothing more.Sem arquivos, sem rede, com limites de instruções e de memória. A maioria dos plugins não precisa de mais nada.

files

Reads or writes any file through import, export and save. With API 2 a plugin can instead receive just the file you pick.Lê ou grava qualquer arquivo por importar, exportar e salvar. Com a API 2 o plugin pode, em vez disso, receber só o arquivo que você escolher.

tools

Runs an external program, such as a simulator, but only one you approve and configure yourself.Roda um programa externo, como um simulador, mas só um que você aprove e configure.

Review anywayExamine mesmo assim

The index checks entries and archives, and a maintainer reads each plugin before merging, but read a plugin's code before you trust it.O índice verifica entradas e arquivos, e um mantenedor lê cada plugin antes do merge, mas leia o código de um plugin antes de confiar nele.

For developersPara desenvolvedores

Publish your pluginPublique o seu plugin

Keep the code in your own repository. Here you add one small file that says where each release is and what it asks for. Mantenha o código no seu próprio repositório. Aqui você acrescenta um arquivo pequeno que diz onde está cada release e o que ela pede.

  1. Write the plugin: a plugin.toml manifest and a main.lua that registers commands with ccad.command.Escreva o plugin: um manifesto plugin.toml e um main.lua que registra comandos com ccad.command.
  2. Attach a .zip of it to a release of your repository.Anexe um .zip dele a uma release do seu repositório.
  3. Open a pull request adding plugins/<id>.toml.Abra um pull request que acrescente plugins/<id>.toml.
  4. The checks download your archive and compare it with the entry; once merged, it appears here.As verificações baixam o seu arquivo e o comparam com a entrada; depois do merge, ele aparece aqui.
